## Hugging Face API

For the API part of the assignment, I created a Python script using the Hugging Face `huggingface_hub` library.

The script:

- Sends a prompt to an AI model.
- Prints the model's response in the terminal.

Model used:

`deepseek-ai/DeepSeek-V3-0324`
